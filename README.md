# BatchSheetMetallToDXF
Macros for Solidworks. Works with assemblies, converts sheet metall to .dxf format.

## Русский

Макрос ExportDXF_v1.swp создан для пакетного экспорта DXF из сборок Solidworks. Его надо запускать с открытой активной сборкой. Он ориентирован для экспорта листового металла, поэтому будет экспортировать dxf тех деталей, которые были созданы как листовой металл.

В настоящее время реализован функционал пакетного экспорта, создание папки с dxf в папке, где находится сборка, с названиями файлов по шаблону "Толщина_материал_проект_сборка_деталь_количество". Реализован экспорт конфигураций деталей, участвующих в сборке, в таком случае файл будет нести в себе информацию конфигурации из названия. Экпорт dxf реализован пока только в виде геометрии, для экспорта гравировок функционал будет добавлен позднее.

Для запуска макроса достаточно скачать файл с ним и запустить через меню макросов Solidworks.

### Требования и ограничения
1. Сборка и детали в ней должны быть сохранены локально. Несохраненые детали, или детали в созданные сборке и хранящиеся виртуально, обрабатываться не будут. 
2. При запуске макроса необходимо выбрать материал детали. Пока реализован выбор только нержавеющей стали и черновой стали.
3. Многотельный листовой металл не обрабатывается и может привести к ошибкам, такой функционал будет реализован позднее.
4. Название сборки и название детали напрямую влияют на имя файла dxf, поэтому рекомендуется назвать их в четком и структурируемом порядке.
5. Также не рекомендуется начинать названия с цифр, они будут удаляться и оставаться только слова, в случае если название состоит целиком из цифр, они удаляться не будут.
